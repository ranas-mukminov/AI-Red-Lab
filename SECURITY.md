# Security Policy

## Scope

This repository is a local evaluation lab. It is not a service and not a
target. Its test cases are for models you own and run locally.

## Reporting a problem in this repository

Open an issue describing the file and the problem. Do not include API
keys, credentials, real model outputs containing personal data, or any
data from a production system.

## Responsible disclosure

If a local-model evaluation finds a weakness in a model you own, the
finding belongs to you and to the model's owner under whatever terms
govern that model. Findings about third-party models are out of scope
for this lab and must not be produced with it.

## Out of scope

Probing production models or services, extracting training data or
personal data, bypassing real production safeguards, and sharing
jailbreak prompts for use against live services are not authorised by
this repository.
